# Bom Peregrino Pizza Gourmet

Site institucional em HTML/CSS/JS puro para a pizzaria Bom Peregrino.

## Rodar localmente

Abra `index.html` no navegador, ou sirva a pasta com qualquer servidor estático:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Estrutura

- `index.html` — conteúdo do site
- `styles.css` — estilo (paleta preto/vermelho/dourado inspirada na logo)
- `script.js` — menu mobile e pequenos comportamentos
- `assets/img` — artes dos rodízios e do grupo VIP
- `assets/video` — vídeo do Chefinho
